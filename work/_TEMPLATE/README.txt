상세 페이지 만드는 법 — 포토샵 · 일러스트 · 피그마

━━━ 1. 작업 ━━━
아트보드(프레임) 가로 2800px, 세로는 자유 (1600–3500px 권장)
Behance처럼 이미지끼리 여백 없이 위아래로 붙어서 보입니다.
→ 제목·설명 글, 여백, 배경색은 이미지 안에 직접 디자인하세요.

  한 장 가로 꽉 차게      2800 × 자유
  두 장 나란히           각 1400 × 1750 (또는 1400 × 1400) — 두 장 같은 크기
  영상                  1920 × 1080 MP4, 소리 없음, 15MB 이하

━━━ 2. 내보내기 ━━━
JPG · 품질 80 · sRGB · 장당 1.5MB 이하
  포토샵   파일 > 내보내기 > 대지를 파일로 / 내보내기 형식
  일러스트  파일 > 내보내기 > 화면용으로 내보내기 (대지 선택)
  피그마   프레임 선택 > Export > JPG 1x

━━━ 3. 파일 이름 = 순서 ━━━
  01.jpg              ← 맨 위
  02.jpg
  03a.jpg  03b.jpg    ← 같은 번호 + a/b = 두 장 나란히
  04.mp4              ← 영상도 번호로 순서 지정
  05.jpg
  cover.jpg           ← Work 목록 썸네일 (4:5, 1600×2000)

  번호 뒤에 설명을 붙여도 됩니다: 02_로고 시스템.jpg

━━━ 4. 반영 ━━━
프로젝트 폴더(예: w15_web/)에 넣고 채팅에서 "media 동기화" 라고 말하면 끝.
(git 사용 시: node tools/build-media.mjs → git push)

※ layout.json 은 쓰지 않아도 됩니다. 순서를 글 블록 등으로 세밀하게 짜고 싶을 때만 쓰는 고급 옵션입니다.
